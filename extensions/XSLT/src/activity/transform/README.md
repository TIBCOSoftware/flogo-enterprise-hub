## Settings

The Settings tab has the following fields:

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |

### Input Settings

The Input tab has the following fields:

| Field          | Type   | Required | Description          |
| -------------- | ------ | -------- | -------------------- |
| xmlDocument    | string | true     | A valid XML Document |
| xsltStylesheet | string | true     | An XSLT Style Sheet  |

### Input

None

### Output Settings

The Output Settings tab has the following field:

| Field        | Type   | Description                |
| ------------ | ------ | -------------------------- |
| outputString | string | Output from XSLT processor |
