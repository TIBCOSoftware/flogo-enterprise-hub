================================================================================
HOSPITAL MANAGEMENT API - ENDPOINTS DOCUMENTATION
================================================================================

Base URL: http://localhost:3000/api

================================================================================
APPOINTMENTS
================================================================================

1. GET /appointments
   Description: Retrieves a list of all appointments in the system
   
   Request: None (GET request)
   
   Response:
   [
     {
       "id": "APT-001",
       "patientId": "P-2024-001",
       "doctorId": "DOC-101",
       "dateTime": "2024-01-20T10:00:00Z",
       "status": "scheduled"
     }
   ]

--------------------------------------------------------------------------------

2. GET /appointments/{id}
   Description: Retrieves a specific appointment by its unique identifier
   
   Request: None (GET request)
   Path Parameter: id (e.g., "APT-001")
   
   Response:
   {
     "id": "APT-001",
     "patientId": "P-2024-001",
     "doctorId": "DOC-101",
     "dateTime": "2024-01-20T10:00:00Z",
     "status": "scheduled"
   }

--------------------------------------------------------------------------------

3. POST /appointments
   Description: Creates a new appointment for a patient with a doctor
   
   Request:
   {
     "patientId": "P-2024-001",
     "doctorId": "DOC-101",
     "dateTime": "2024-01-20T10:00:00Z",
     "reason": "Routine checkup"
   }
   
   Response:
   {
     "id": "APT-001",
     "patientId": "P-2024-001",
     "doctorId": "DOC-101",
     "dateTime": "2024-01-20T10:00:00Z",
     "status": "scheduled"
   }

--------------------------------------------------------------------------------

4. PUT /appointments/{id}
   Description: Updates an existing appointment's details or status
   
   Request:
   {
     "dateTime": "2024-01-20T14:00:00Z",
     "status": "confirmed"
   }
   Path Parameter: id (e.g., "APT-001")
   
   Response:
   {
     "id": "APT-001",
     "patientId": "P-2024-001",
     "doctorId": "DOC-101",
     "dateTime": "2024-01-20T14:00:00Z",
     "status": "confirmed"
   }

PHARMACY ORDERS
================================================================================

5. GET /pharmacy/orders
   Description: Retrieves a list of all pharmacy orders
   
   Request: None (GET request)
   
   Response:
   [
     {
       "id": "PH-001",
       "patientId": "P-2024-001",
       "medication": "Aspirin",
       "quantity": 30,
       "status": "processing"
     }
   ]

--------------------------------------------------------------------------------

6. GET /pharmacy/orders/{id}
   Description: Retrieves a specific pharmacy order by its unique identifier
   
   Request: None (GET request)
   Path Parameter: id (e.g., "PH-001")
   
   Response:
   {
     "id": "PH-001",
     "patientId": "P-2024-001",
     "medication": "Aspirin",
     "quantity": 30,
     "status": "processing"
   }

--------------------------------------------------------------------------------

7. POST /pharmacy/orders
   Description: Creates a new pharmacy order for medication
   
   Request:
   {
     "patientId": "P-2024-001",
     "medication": "Aspirin",
     "quantity": 30,
     "dosage": "100mg"
   }
   
   Response:
   {
     "id": "PH-001",
     "patientId": "P-2024-001",
     "medication": "Aspirin",
     "quantity": 30,
     "status": "processing"
   }

--------------------------------------------------------------------------------

8. PUT /pharmacy/orders/{id}
   Description: Updates an existing pharmacy order's status or details
   
   Request:
   {
     "status": "ready",
     "quantity": 30
   }
   Path Parameter: id (e.g., "PH-001")
   
   Response:
   {
     "id": "PH-001",
     "patientId": "P-2024-001",
     "medication": "Aspirin",
     "quantity": 30,
     "status": "ready"
   }

    Description: Retrieves a list of all billing records in the system

        "dueDate": "2024-02-01"
      }
    ]

--------------------------------------------------------------------------------

14. GET /billing/{id}
    Description: Retrieves a specific billing record by its unique identifier
    
    Request: None (GET request)
    Path Parameter: id (e.g., "BIL-001")
    
    Response:
    {
      "id": "BIL-001",
      "patientId": "P-2024-001",
      "amount": 1500.00,

15. POST /billing
    Description: Creates a new billing record for a patient
    
    Request:

      "patientId": "P-2024-001",
      "amount": 1500.00,
      "description": "Consultation and tests"
    }
    
    Response:
    {
      "id": "BIL-001",
      "patientId": "P-2024-001",
      "amount": 1500.00,
      "status": "pending",
      "dueDate": "2024-02-01"
    }

--------------------------------------------------------------------------------

16. PUT /billing/{id}
    Description: Updates an existing bill's status or amount
    
    Request:
    {
      "status": "paid",
      "amount": 1500.00
    }
    Path Parameter: id (e.g., "BIL-001")
    
    Response:
    {
      "id": "BIL-001",
      "patientId": "P-2024-001",
      "amount": 1500.00,
      "status": "paid",
      "dueDate": "2024-02-01"
    }

================================================================================
NOTES
================================================================================

- All dates should be in ISO 8601 format (YYYY-MM-DD for dates, 
  YYYY-MM-DDTHH:MM:SSZ for date-time)
- Status values:
  * Appointments: "scheduled", "confirmed", "completed", "cancelled"
  * Pharmacy Orders: "processing", "ready", "dispensed", "cancelled"
  * Billing: "pending", "paid", "overdue", "cancelled"
- All POST requests return 201 status code on success
- All PUT requests return 200 status code on success
- All GET requests return 200 status code on success
- 404 status code returned when resource not found
